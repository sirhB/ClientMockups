# Shearwater Organic Coffee Roasters — website demo

Five switchable themes for the Trumbull, CT organic coffee roaster (prior site suspended).

**Themes:** Tide Chart · Label Wall · Trade Counter · Macro · Color Block  
**Pages:** Home, Shop, Product, Subscriptions, Wholesale, Our Story, Visit/Contact

Facts/photos from `research.md` and archived copies of their own site. Shop prices are 2019 archive placeholders. Fairfield/Westport cafés have closed — the Trumbull roastery counter is the visit point.

Stripe stub: `assets/js/config.js` (`payments.enabled: false`). Never commit secret keys.

Pitch: `pitch/pricing-sheet.pdf`, `pitch/pitch-wallpaper.png`
