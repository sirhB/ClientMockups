Website redesign mockups, one directory per client. Live: https://sirhb.github.io/ClientMockups/

| Client | Folder | Live demo |
|---|---|---|
| The Classic Car Gallery (Black Rock, CT) | `classic-car-gallery/` | https://sirhb.github.io/ClientMockups/classic-car-gallery/ |
| New England Classics (Stratford, CT) | `new-england-classics/` | https://sirhb.github.io/ClientMockups/new-england-classics/ |
